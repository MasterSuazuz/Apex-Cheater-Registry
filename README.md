# Apex Cheater Registry

Записывает экран и звук Apex Legends, по F8 вырезает момент и кладёт его в досье того, кто на экране:
наблюдаемого игрока или тебя самого. Чит ли это — решаешь ты, оценкой от 1 до 5.

Программа **только записывает экран и звук** (как OBS): не читает память игры и не внедряется в неё.

## Запуск

Ярлык **«Apex Cheater Registry»** в папке программы (с иконкой) или `run.bat`. При первом запуске `run.bat`
сам поставит зависимости (нужен Python 3.11+). Ярлык можно скопировать на рабочий стол.

## Как работает

1. **F9 — включить/выключить запись** (или кнопка в «Эфире»). Сама запись не включается никогда.
   Работает как повтор в NVIDIA: на диске лежат только последние N секунд видео и звука, всё старше
   стирается само. **N задаётся первой карточкой в Настройках — «Повтор»** (по умолчанию 30 с).
2. **F8 — сохранить момент.** Программа в момент нажатия читает экран:
   - **режим зрителя** («В эфире» → «Режим зрителя»): ник с красной плашки, **идентификатор** из строки
     «Идентификатор: …» (главный ключ досье), тиммейты и легенда — момент уходит в досье этого игрока;
     клип начинается не раньше, чем его начали показывать;
   - **своя игра**: момент уходит в твоё досье с тегом **[OWNER]** (заводится один раз, ник — из списка отряда).
3. **Досье** — всё редактирование: ник, ID, легенда, теги, оценка и заметка у каждого момента, легенда
   момента, текст жалобы, экспорт. Видео — с громкостью и **на весь экран** (кнопка или двойной щелчок;
   Esc — выход, пробел — пауза, ← → — 5 секунд). **Обрезка — кнопка ✂**: 1-й щелчок ставит
   на полосе видео скобку [, 2-й — ], 3-й обрезает. Скобки можно перетаскивать мышью, ✕ — убрать их.
   Вырезанное удаляется из досье, файл становится меньше.

## Легенды

Портреты всех легенд программа сама скачивает с вики Apex Legends при первом запуске (в `assets/legends`,
в репозиторий они не входят — это арт игры). По ним она узнаёт легенду
по портрету в списке отряда сразу, без обучения. У каждого момента в досье видна иконка легенды, есть
фильтр по легендам. Вышла новая легенда — Настройки → «Скачать новых легенд». Если программа ошиблась —
исправь легенду в досье, она запомнит.

## Теги и закрепление

Теги досье: **OWNER** (твоё), **CHEATER**, **PRO**, **NOOB** — ставятся кнопками в досье, по ним есть фильтр
в списке. ★ закрепляет досье вверху списка.

## Звук

Настройки → «Звук»: звук игры (всё, что слышно в наушниках/колонках, включая голосовой чат), микрофон,
выбор устройств и громкость микрофона.

## Оценка момента

| | |
|---|---|
| 1 | мувмент, макрогейминг |
| 2 | нет чита |
| 3 | хорошая стрельба |
| 4 | подозрительно |
| 5 | чит |

В текст жалобы EA попадают моменты с оценкой 4 и 5.

## Язык

Русский и английский: Настройки → Язык (после перезапуска).

## Файл .apexcase

Это обычный ZIP: `timeline.txt`, `report.html` (видео играют после распаковки), `ea_report.txt`,
`clips/*.mp4` (видео со звуком), `frames/*.jpg`, `portrait.png`, `manifest.json`.
Имя файла: `<ник>_ID<идентификатор>.apexcase`.
